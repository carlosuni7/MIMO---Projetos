# 🚀 Meu Diário de Estudos Dev - Carlos

Este repositório contém meus códigos, exercícios e projetos práticos desenvolvidos durante minha jornada de aprendizado em tecnologia.
Começou com uma pasta para exercicios do app Mimo e se estendeu para exercicios feitos na faculdade e utilizando de IA.

---

## 📂 Organização do Repositório

O projeto está dividido por tecnologias e níveis de dificuldade:

* **[HTML & CSS](./CSS):** Estudos de layout, Flexbox e CSS Grid.
* **[JavaScript](./JavaScript):** Lógica de programação, manipulação de DOM e eventos.
* **[TypeScript](./TypeScript):** Evolução do JS com tipagem estática.
* **[React](./React):** Criação de interfaces modernas e componentes.
* **[Python](./Python):** Exercícios de lógica e automação.
* **[Java](./Java):** Programação Orientada a Objetos e estruturas de dados.

## 📝 Como rodar os projetos

### Para Java:
1. Navegue até a pasta `Java/Exercicios`.
2. Compile com: `javac NomeDoArquivo.java`
3. Rode com: `java NomeDoArquivo`

### Para TypeScript:
1. Entre na pasta `TypeScript`.
2. Compile o código: `tsc index.ts --watch`
